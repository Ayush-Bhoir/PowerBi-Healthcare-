# 🏥 Power BI Dashboard – Healthcare Analytics

📌 Summary
An interactive Healthcare Analytics Dashboard developed using Power BI to analyze hospital operations and patient data. This project transforms raw healthcare data into clear, actionable insights to support data-driven decision-making in healthcare management.

🎯 Objective
Analyze hospital and patient data effectively
Track key healthcare performance metrics
Understand patient demographics and diagnosis trends
Improve operational efficiency through data insights

📊 Dashboard Features
Hospital Overview
Total patient count
Average length of stay
Bed occupancy rate
Readmission trends
Patient Insights
Patient demographics
Common diagnoses
Referral and admission patterns

🚀 Impact
Simplified complex healthcare datasets into intuitive visuals
Improved visibility into hospital performance and patient trends
Enabled faster, evidence-based decision-making
Demonstrated strong data storytelling and visualization skills

🛠 Tools & Technologies
Power BI
DAX
Data Modeling
Data Visualization

# Description
This project demonstrates the use of Power BI and DAX to convert healthcare data into meaningful insights. By focusing on key hospital KPIs and patient analytics, the dashboard highlights how data analytics can improve healthcare operations and support informed decision-making.
